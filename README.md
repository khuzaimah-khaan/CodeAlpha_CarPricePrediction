# Car Price Prediction

## Project Overview

This project uses machine learning to predict the selling price of used cars based on vehicle-related features.

## Objective

The main objective is to build regression models that can estimate car prices and compare their performance using appropriate evaluation metrics.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Workflow

1. Load the car dataset
2. Inspect and clean the data
3. Check missing values and duplicates
4. Perform exploratory data analysis
5. Create relevant features
6. Encode categorical variables
7. Split the data into training and testing sets
8. Train regression models
9. Evaluate model performance
10. Compare the models
11. Select the best-performing model

## Models Used

* Linear Regression
* Decision Tree Regressor
* Random Forest Regressor

## Evaluation Metrics

The models were evaluated using:

* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)
* R² Score

## Result

The Decision Tree Regressor achieved an R² score of approximately 0.83 on the test data, with an MAE of approximately 1.11 and RMSE of approximately 2.11.

## Conclusion

The project demonstrates how machine learning regression techniques can be applied to estimate used-car prices from vehicle characteristics. The models provide a practical comparison of different regression approaches for price prediction.
